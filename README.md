A simple and interactive notes web application built using HTML, CSS, and JavaScript. This app allows users to create, edit, and delete notes بسهولة with a clean and user-friendly interface.

Features:
- Create new notes
- Edit existing notes
- Delete notes
- Auto-save using local storage
- Responsive design (works on mobile & desktop)
  
Technologies Used:
- HTML
- CSS
- JavaScript (DOM manipulation & events)
  
How It Works:
- Notes are created dynamically using JavaScript
- Data is stored in the browser using localStorage
- Changes are updated in real-time without reloading the page
  
Project Structure:
project-folder/
│── index.html
│── style.css
│── script.js

How to Run: 
- Download or clone the repository
- Open index.html in your browser
- Start writing your notes
  
Future Improvements:
- Add search functionality
- Add categories/tags
- Sync notes with a backend database
